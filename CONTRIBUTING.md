# Contributing

Thanks for helping Logic Nudge keep code examples clear and correct.

- Open an issue with a minimal reproduction and the expected/actual behavior.
- Before submitting changes, run `npm run verify` using Node.js 20+.
- Preserve the original educational behavior unless you're fixing a documented error.
- Explain important runtime/platform assumptions. Be especially careful with asynchronous scheduling, `this` binding, the Temporal Dead Zone, and shallow copies.
- Never paste secrets, API keys, real people's private data, or account credentials.
- Keep changes focused; avoid new dependencies unless truly necessary.

**Contributor privacy:** GitHub may display contributor account names and commit metadata on public work. Use a suitable public identity for any contributions you choose to make.

By submitting a contribution, you agree to license it under this repository's MIT License.
